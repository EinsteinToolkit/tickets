## Before opening an issue

Search the [existing issues](https://github.com/EinsteinToolkit/tickets/issues) first. If one already describes your problem, add any useful new details there instead of opening a duplicate.

Issues are public. Never include passwords, access tokens, private keys, or other sensitive information.

## How to submit an issue

1. Sign in to GitHub, then select **[New issue](https://github.com/EinsteinToolkit/tickets/issues/new)**.
2. Write a short, specific title.
3. Describe the problem or requested improvement.
4. Add the technical details needed to understand and reproduce it.
5. Review the issue, remove any sensitive information, then submit it.

### What to include

- The affected component or thorn.
- Your Einstein Toolkit release name or Git commit.
- Your operating system and relevant compiler, MPI, and dependency versions.
- For bugs, exact steps or a small example that reproduces the problem.
- For enhancements, the use case and desired behavior.
- For bugs, what you expected to happen and what happened instead.
- Relevant error messages, logs, screenshots, or configuration files.

Clear, focused reports help maintainers investigate and respond faster.
